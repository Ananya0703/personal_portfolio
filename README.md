# Personal Portfolio

A static personal portfolio built with:

- Next.js (App Router)
- React
- Tailwind CSS
- Framer Motion

## Requirements

- Node.js 18+ recommended
- npm

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
```

## Notes

- Resume download uses `public/resume.pdf`.
- Project images live in `public/project-images/`.
